
# 🦚 Krishna Birthday Surprise 🎂

A special birthday surprise website created using Python and Streamlit, featuring a beautiful Little Krishna opening, flute music, animated birthday celebrations, and an interactive cake.

## ✨ Features

- 🦚 Little Krishna video introduction
- 🎵 Background flute music
- 🎂 Interactive birthday cake
- 🕯️ Blow-out candle animation
- 🎉 Party poppers and confetti effects
- 🎈 Floating animated balloons
- 💗 Birthday wishes and replay option
- 📱 Responsive layout for mobile and desktop

## 🛠️ Technologies Used

- Python
- Streamlit
- HTML
- CSS
- JavaScript

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/krishna-birthday-surprise.git
```

### 2. Open the project folder

```bash
cd krishna-birthday-surprise
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
